Микросервис для отправки уведомлений на почту при событиях из Kafka.

Возможности сервиса:

- Получение событий из Kafka (создание/удаление пользователя)
- Отправка email на почту пользователя
- REST API для ручной отправки писем

Технологии:

- Java 21
- Spring Boot 3.4.1
- Apache Kafka
- Spring Mail
- Maven
- JUnit 5
